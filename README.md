# Private Sekai

## 项目简介

本项目用于模拟游戏 **初音未来 -歌姬计划- （初音ミク -プロジェクト ディーヴァ-，Hatsune Miku: Project DIVA）** 游戏测试服务端，供个人技术研究、协议分析、逆向学习等用途。所有功能仅限于本地测试，严禁用于任何形式的公开传播、开服或商业用途。

### 当前可用范围

- **基础账号与日常操作**：已接入注册登录、引导、引继、编队、卡牌培养、商店、剧情、任务、好友及资料编辑；各功能的限制见下表。
- **普通单人演出**：已有开局、结算、成绩保存、曲目成就及部分任务联动；奖励仍不完整，高分结算可能漏发经验或掉落。
- **挑战演出**：已有首次解锁、单／双卡手动开局及多项结算业务组件；尚不能通过完整 HTTP 流程完成挑战结算。
- **实时通信与私人房间**：协议客户端已连接官方 `multi` UDP，完成握手、clientKey 确认、加密 Ping、三次 Echo、普通规则私人空房间预留、分配房号及大厅设置；入房和多人演出尚未接入，服务端尚无对应实时服务。

### 已按规则泛化的部分

- **评分与曲目成就**：按歌曲参考谱面查询全部评分门槛，遍历 master 成就条件和奖励；支持一次跨多档与重复结算去重。
- **任务门槛**：贴图、服装、Vocal 收集及新手总任务按 master 定义处理多个门槛；部分最终达成和领奖仍缺官方样本。
- **成长与固定奖励**：玩家跨级奖励按跨过的 master 等级处理；挑战高分固定奖励按角色和分数查表。最高等级、部分解锁奖励与随机掉落不在此完成范围内。
- **房间预留配置**：普通／自定义规则按对应 clientConfigs 读取 TTL，属性编码支持不同设置、总力上下限及难度数组；官方实测目前只覆盖普通规则默认预留。

规则明确时覆盖未抓包的输入；规则不明时保留缺口。尤其不能把固定奖励查表等同于随机掉落池已还原，也不能把新增一个评分常量视为全档奖励已实现。

### 当前主要缺口

- **普通演出奖励仍有样本硬编码**：评分掉落只覆盖两个谱面等级／评分组合，其余返回空；随机资源池和权重尚未还原。B 档官方对拍已确认漏发经验，不能把当前结算视为完整实现。
- **每日奖励和多人流程未完成**：每日加成由多人／Cheerful 通关触发，普通单人不触发；当前剩余次数误用体力消耗，不能改为固定次数。基础实时通信、私人预留、房号分配及大厅设置已实测。入房还需完整构造编队总力、卡牌、称号、服装等玩家资料，处理同步及退出；可靠 ACK 或入房命令成功响应均不足以证明已经入房。
- **挑战循环未完成**：阶段、角色升级、固定高分奖励、首次出勤、D／C 经验、生日奖励及部分 marathon 活动奖励已有业务实现和专项回放，但完整 HTTP 结算尚未接入。后续出勤、跨日、EX、Auto、更多编队槽位、高档经验及随机掉落仍待补齐。
- **兑换、资源与任务覆盖有限**：材料兑换的周期和限量、部分活动奖励资源、称号升级、角色满级／解锁奖励及部分角色任务合并领奖仍有限制。
- **抽卡及扩展资料待审计**：抽卡特殊消耗、额外奖励和保底规则未完整确认；部分好友关系转换及扩展资料仍会拒绝处理，不能视为全部兼容。
- **泛化与官方验证分开记录**：评分和成就已使用完整 master 门槛；收集任务及新手总任务也已支持多门槛，但部分高门槛只有本地测试和逆向依据，尚无官方实测。

当前正在核对私人入房所需的玩家资料和编队总力计算；完成资料构造、入房同步及退出处理后，再验证完整私人房间流程。普通演出经验与掉落规则、多人每日奖励及挑战完整结算继续保留为主要待办，再逐步扩展兑换、资源和任务边界。
